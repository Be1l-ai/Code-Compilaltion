# Chatbot Documentation

## Overview
The **Chatbot** is a simple command-line bot that can answer few specific questions. It doesn't have any intelligence and only answers questions that are saved into it's initializer.

## Features
- It manages user interactions, processes input messages, and generates appropriate responses. Key features include:

- **Initialization**: Configurable with various parameters.
- **Message Handling**: Accepts user input and does absolutely nothing.
- **Extensibility**: Being empty allows integration with external APIs, plugins, or custom logic for advanced conversational flows.
