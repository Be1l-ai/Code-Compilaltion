# Minigames

Collection of simple CLI games.

## Games Included

### 1. Jack en Poy (Rock-Paper-Scissors)

```sh
python3 code_com/minigames/jack_en_poy.py
```
Classic rock-paper-scissors vs computer.

### 2. Number Guessing Game

```sh
python3 code_com/minigames/number_guessing_game.py
```
Guess a random number between 1-100.

### 3. Math Quiz Game- Random computer choice```

```sh
python3 code_com/minigames/quiz_game.py
```
Answer random math problems.

## Notes

- all games have replay functionality so you can play multiple rounds
- if you type something invalid the game will tell you
- theyre pretty simple but i might add more features later
