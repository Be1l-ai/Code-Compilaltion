# Calculator

Extended calculator with additional math operations.

## Features

- Inherits from BasicCalculator (add, subtract, multiply, divide)
- Square calculation
- Power calculation
- Square root
- Percentage- All basic calculator operations
- Expression evaluation
- Inherits from BasicCalculator (add, subtract, multiply, divide)- Square and power functions

## Run Directly

```
python3 code_com/calculator/calculator.py
```

## Notes

- Uses `eval()` for expression evaluation
- Power function uses iterative calculation
